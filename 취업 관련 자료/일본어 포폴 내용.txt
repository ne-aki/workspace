6. PROJECTS（プロジェクト）
💡 スマートファーム・畜舎管理 Web & アプリ開発

React・React Native・Spring Boot による IoT連携型統合管理システム

プロジェクト概要

Raspberry Pi で収集した温度・湿度・照度・空気質データを統合管理し、Webとアプリの両方でリアルタイム監視を可能にしたチーム開発プロジェクトです。
商品購入機能を備えたWebショッピングモールも併行して開発し、フロント・バックエンド・DBの全領域を経験しました。

開発期間

1次（2024/09/11 – 09/24）
Raspberry Pi + Python でIoTデバイス開発、データ収集・自動制御ロジック実装
2次（2024/09/25 – 10/16）
React ベースのスマートファーム連携、家畜購入/販売Webサイト構築
3次（2024/10/17 – 11/14）
React Native でモバイルアプリ開発、リアルタイムデータ閲覧機能を実装

🧩 主な担当・成果
① 中복コードのリファクタリング

Home / 新商品ページの共通ロジックをコンポーネント化し、
32行の重複コードを削減。

② Outlet データ共有（useOutletContext）

詳細ページのタブ間で必要な商品データを一度のAPI呼び出しで共有。
不要なAPI呼び出しの削減・ページ速度改善を実現。

③ Pagination 実装

1ページ50件以上のデータでUIが崩れる問題を解決。
1ページ8件に制御し、ユーザビリティを改善。
totalItems の渡し方の誤りを発見・修正し、状態管理への理解を深めた。

④ データ可視化（Chart.js）

温度・湿度・照度などの1〜4週間データを
最高・最低・平均値とともに可視化。
WHERE句漏れによるデータ異常もSQL改修で解決。
